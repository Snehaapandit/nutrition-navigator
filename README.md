#  Nutrition Navigator – Fruit & Vegetable Recognition App

An AI-powered nutrition and food recognition project that identifies **fruits and vegetables using deep learning** and helps users navigate nutritional food choices.

Built using **Python, TensorFlow/Keras, and Streamlit**.

##  Project Overview

Nutrition Navigator is a deep learning-based application that classifies fruits and vegetables from images using a trained model.

The project helps users identify food items and can be extended to provide nutrition information such as calories, protein, carbs, and vitamins.

##  Features

* Fruit and vegetable image classification
* Deep learning image recognition
* Pre-trained `.h5` model
* Streamlit web app interface
* Image upload support
* Dataset training notebook
* Testing notebook included

##  Tech Stack

* Python
* TensorFlow / Keras
* Streamlit
* NumPy
* OpenCV
* Jupyter Notebook
